HEICとは？ なぜWindowsでそのまま開けないのか

HEIC（High Efficiency Image Container）は、Appleが2017年のiOS 11からiPhone・iPadの標準撮影形式として採用した画像フォーマットです。国際規格であるHEIF（High Efficiency Image File Format）をベースにしており、JPEGと同程度の画質を約半分のファイルサイズで保存できるのが最大の特長です。iPhoneのストレージを節約できる優れた形式ですが、その分、対応していない環境では扱いづらいという弱点があります。

特にWindowsパソコンでは、標準状態ではHEICファイルをダブルクリックしても開けないことが多く、「HEIF 画像拡張機能」や有料の「HEVC ビデオ拡張機能」を別途インストールしないと表示できない場合があります。また、会社の申請システムやWebサービスへの画像アップロード、年賀状印刷サービス、古い画像編集ソフトなどはJPEGしか受け付けないことが多く、iPhoneから写真を渡された相手が開けない・使えないというトラブルが頻繁に起こります。こうした場面で必要になるのが、HEICからJPG（JPEG）への変換です。

iPhone側でJPG撮影に切り替える設定（互換性優先）

今後撮影する写真を最初からJPEGで保存したい場合は、iPhoneの設定を変更できます。手順は次のとおりです。

  1. 「設定」アプリを開く
  2. 「カメラ」をタップ
  3. 「フォーマット」をタップ
  4. 「高効率」から「互換性優先」に切り替える

「互換性優先」にすると以後の写真はJPEG、動画はH.264で保存され、WindowsやWebサービスでもそのまま扱えるようになります。ただしファイルサイズは高効率（HEIC/HEVC）の約2倍になるため、ストレージ容量と相談して選んでください。すでに撮影済みのHEIC写真はこの設定では変換されないので、本ツールでまとめてJPGに変換するのが手軽です。

使い方 — HEIC写真をまとめてJPGに変換する手順

本ツールの使い方は3ステップです。①上のエリアにHEIC/HEIFファイルをドラッグ＆ドロップ（またはクリックして選択）します。複数ファイルの同時選択に対応しています。②必要ならJPG品質スライダー（0.5〜1.0、初期値0.9）を調整するか、無劣化のPNG出力に切り替えます。③「変換する」を押すと1枚ずつ順番に変換され、各ファイルの状態が「待機中→変換中→完了」と表示されます。完了したファイルは個別にダウンロードできるほか、2枚以上ある場合は「まとめてZIPでダウンロード」で一括保存できます。途中で変換に失敗したファイルがあってもそこで止まらず、残りのファイルの変換は継続されます。

アップロード型の変換サイトとの違い

HEIC変換サービスの多くは、写真をいったんサーバーへアップロードし、サーバー側で変換してからダウンロードさせる「アップロード型」です。この方式は、プライベートな写真が外部サーバーを経由するというプライバシー上の不安に加え、通信量が大きい・枚数制限や有料プランがある・混雑時に待たされるといったデメリットがあります。

本ツールは「ブラウザ完結型」です。変換処理はすべてお使いの端末のブラウザ内（JavaScript）で実行され、写真がネットワークに送信されることは一切ありません。家族の写真や身分証の写しなど、外部に出したくない画像でも安心して変換できます。両者の違いをまとめると次のとおりです。

項目本ツール（ブラウザ完結型）アップロード型サイト
写真の送信なし（端末内で完結）あり（サーバーを経由）
プライバシー外部に出ないため安全運営者のサーバーに一時保存される
通信量ページ読み込み分のみ写真の容量分だけ発生
料金・制限無料・枚数制限なし無料枠に枚数制限がある場合が多い
処理速度端末性能に依存回線速度と混雑状況に依存

よくある質問

HEICからJPGに変換すると画質は落ちますか？
JPEGは非可逆圧縮のため厳密には再圧縮による劣化がありますが、初期値の品質0.9であれば見た目にはほとんど分からないレベルです。品質スライダー（0.5〜1.0）を上げるほど高画質・大容量になります。画質を一切落としたくない場合はPNG出力に切り替えてください（可逆圧縮のため劣化しませんが、ファイルサイズは大きくなります）。
一括で何枚まで変換できますか？
枚数の上限は設けていませんが、変換はお使いの端末のメモリ上で行われるため、端末性能により実際の上限は変わります。目安として一度に20〜30枚程度までにし、大量にある場合は数回に分けて変換することをおすすめします。変換は1枚ずつ順番に処理され、途中でエラーになったファイルがあっても残りは継続されます。
写真をアップロードするのは安全ですか？
本ツールはそもそも写真をアップロードしません。ファイルの読み込みから変換、ダウンロードまですべてお使いのブラウザ内（JavaScript）で完結し、サーバーへの送信は一切行われないため、プライベートな写真でも安心して利用できます。無料・登録不要です。
HEIF形式にも対応していますか？
はい。HEIC（.heic）はHEIF（High Efficiency Image File Format）というコンテナ規格の一種で、本ツールは.heicと.heifの両方の拡張子に対応しています。iPhoneやiPadで撮影した写真のほか、一部のAndroid端末やデジタルカメラが出力するHEIFファイルも変換できます。
iPhoneの写真しか変換できませんか？
いいえ。HEIC/HEIF形式のファイルであれば撮影機器を問わず変換できます。iPhone・iPadのほか、HEIF撮影に対応したAndroidスマートフォンやソニー・キヤノンなどのデジタルカメラで撮影したファイルにも対応します。なお、拡張子が.heicでも中身が実はJPEGというファイル（転送アプリが自動変換したものなど）は「変換不要」としてエラー表示になります。
