イベント リッチリザルト 要件チェック
    生成される JSON-LD はページの <head> または <body> 内に貼り付けてください。開始日時・終了日時・販売開始日時はお使いの端末のタイムゾーンオフセットを付けた ISO 8601 形式で出力します。空欄のフィールドは自動的に除外されます。公開後は Google のリッチリザルト テストで検証することをおすすめします。

    Event 構造化データ生成ツールの使い方

    イベント名・日時・開催形態・会場・チケットなどの情報を入力するだけで、schema.org の Event タイプに対応した JSON-LD 構造化データを自動生成する無料ツールです。生成したコードをイベントページの HTML に貼り付けると、Google 検索のイベント表示（リッチリザルト）にイベント名・日時・開催地などが表示されやすくなり、集客とクリック率の向上が期待できます。インストールや会員登録は不要で、入力と生成はすべてお使いの端末内で完結します。

    使い方はシンプルです。上から順にイベントの基本情報を入力していくと、下部のコード欄にリアルタイムで JSON-LD が生成されます。「開催形態」を切り替えると、会場（Place）とオンライン（VirtualLocation）の入力欄が自動で切り替わります。入力を空欄にしたフィールドは出力から自動的に除外されるため、必要な項目だけを埋めれば整った構造化データが得られます。完成したら「コピー」ボタンでクリップボードにコピーし、そのままページに貼り付けてください。

    オフライン・オンライン・ハイブリッドに対応

    開催形態のセレクトで「オフライン（会場）」を選ぶと会場名と住所から Place を、「オンライン」を選ぶと視聴 URL から VirtualLocation を生成します。「ハイブリッド」では両方を location の配列として出力し、eventAttendanceMode にも MixedEventAttendanceMode を自動設定します。オンライン開催が増えた近年のイベント SEO に合わせ、開催形態と location の型を常に整合させて出力します。

    Event 構造化データの主なプロパティ

    Google のイベント リッチリザルトで扱われる代表的なプロパティは次のとおりです。必須項目を満たしたうえで、推奨項目を充実させるほど検索結果での表示が豊かになります。

    プロパティ区分説明
    name必須イベントの名称
    startDate必須開始日時。ISO 8601（タイムゾーン付き）で記述
    location必須開催地。会場は Place、オンラインは VirtualLocation（url 必須）
    endDate推奨終了日時。ISO 8601 で記述
    image推奨イベントの画像 URL
    description推奨イベントの説明文
    offers推奨チケット情報。price / priceCurrency / availability / url / validFrom
    performer推奨出演者・登壇者
    organizer推奨主催者（name / url）
    eventAttendanceMode推奨開催形態（オフライン / オンライン / ハイブリッド）
    eventStatus推奨開催ステータス（予定 / 延期 / 中止 / 日程変更 など）

    日時は ISO 8601 で出力

    開始日時・終了日時・チケットの販売開始日時は、日時入力から 2026-08-01T19:00:00+09:00 のような ISO 8601 形式へ変換して出力します。末尾のタイムゾーンオフセットはお使いの端末の設定（日本なら +09:00）を自動付与するため、地域を含んだ曖昧さのない日時としてマークアップされます。中止・延期などのステータス変更を反映したい場合は、開催ステータスのセレクトを切り替えてください。

    よくある質問

    Event 構造化データとは何ですか？
    Event 構造化データは、コンサート・セミナー・展示会・ワークショップなどのイベント情報を検索エンジンが理解できる形式で記述する schema.org のマークアップです。JSON-LD 形式でページに埋め込むと、Google 検索やイベント表示枠でイベント名・日時・開催地がリッチリザルトとして表示されやすくなります。本ツールは入力内容から Event の JSON-LD をリアルタイムに生成します。
    オンラインイベントにも対応していますか？
    はい。開催形態のセレクトで「オンライン」を選ぶと location が VirtualLocation 型に切り替わり、視聴ページの URL を指定できます。「オフライン（会場）」では Place 型で会場名と住所を、「ハイブリッド」では VirtualLocation と Place の両方を location の配列として出力します。eventAttendanceMode も選択に応じて自動で設定します。
    日時はどの形式で出力されますか？
    開始日時・終了日時は日時入力で受け取り、schema.org が推奨する ISO 8601 形式で出力します。お使いの端末のタイムゾーンオフセット（例：+09:00）を自動付与するため、たとえば 2026-08-01T19:00:00+09:00 のように、地域を含んだ正確な日時としてマークアップされます。終了日時を空欄にした場合は endDate を出力しません。
    入力を空欄にするとどうなりますか？
    空欄のフィールドは JSON-LD から自動的に除外されます。必要な項目だけを埋めればよく、不要な空の値が出力されることはありません。すべて空欄の場合でも、構造を確認できるようにサンプルのイベント情報を使った出力を表示します。実際に使用する際は、ご自身のイベント情報に置き換えてください。
    リッチリザルトに表示されるために必須の項目は？
    Google のイベント リッチリザルトでは name（イベント名）、startDate（開始日時）、location（開催地。オンラインの場合は VirtualLocation と URL）が必須です。image や description、offers、performer、organizer は推奨項目で、埋めるほど表示が充実します。本ツールは必須項目の充足状況を画面のヒントで色分け表示するので、公開前のチェックにご活用ください。
