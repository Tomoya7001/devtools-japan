Organization構造化データ生成ツールの使い方

会社名やURL、ロゴ、住所、電話番号、SNSアカウントなどを入力するだけで、schema.orgのOrganization構造化データ（JSON-LD）を自動生成する無料ツールです。インストールや会員登録は不要で、すべての処理はお使いの端末内のブラウザだけで完結します。入力した情報がサーバーに送信・保存されることはありません。

使い方はかんたんです。まず必須項目である「組織名 / 会社名」を入力すると、下部の出力ボックスにリアルタイムでJSON-LDが生成されます。続けてURL・ロゴ・説明・電話・メール・住所・SNSなどの任意項目を埋めていくと、その内容がすぐにコードへ反映されます。完成したら「コピー」ボタンでコード全体をクリップボードにコピーし、対象ページのHTMLに貼り付けてください。

こんな用途に

コーポレートサイトやサービスサイトのSEO対策として、運営組織の情報を検索エンジンに正しく伝えたいときに便利です。Googleのナレッジパネルやリッチリザルトでロゴや公式SNSを表示させたい場合、Organization構造化データの設置が推奨されます。手書きでJSON-LDを書くと括弧の対応やプロパティ名を間違えやすいですが、本ツールなら入力するだけで正しい形式のコードが得られます。

生成される構造化データの内容

本ツールは、入力内容に応じて @context・@type・name を基本に、url・logo・description・telephone・email などのプロパティを追加します。住所は PostalAddress 型として入れ子で出力し、streetAddress・addressLocality・addressRegion・postalCode・addressCountry のうち入力された項目だけを含めます。SNSやプロフィールのURLは sameAs の配列として出力されます。入力しなかった任意項目は自動的に省略されるため、余計な空プロパティが混ざりません。

プロパティ対応する入力説明
name組織名 / 会社名必須。組織の正式名称
url公式サイトURL組織の公式サイトのURL
logoロゴ画像URLロゴ画像への直接URL
address住所各項目PostalAddress型として入れ子で出力
telephone / email電話・メール連絡先情報
sameAsSNS・プロフィール公式SNS等のURLを配列で出力

設置場所の目安

Organization構造化データは、通常サイト全体の運営組織を表すため、トップページに1つ設置するのが一般的です。生成された <script type="application/ld+json"> のコードを、対象ページのHTMLの <head> 内（<body> 内でも動作します）に貼り付けてください。設置後は、Googleのリッチリザルトテストやスキーママークアップ検証ツールで、構文エラーがないかを確認することをおすすめします。

よくある質問

Organization構造化データとは何ですか？
Organization構造化データとは、schema.orgの語彙を使って企業や組織の情報（名称・URL・ロゴ・住所・連絡先・SNSアカウントなど）を検索エンジンが理解できる形式で記述したものです。多くはJSON-LD形式でHTMLの中に埋め込み、Googleなどの検索エンジンに運営組織の正確な情報を伝えることで、ナレッジパネルやリッチリザルトの表示に役立ちます。本ツールはフォームに入力するだけでこのJSON-LDを自動生成します。
生成したJSON-LDはどこに貼り付ければいいですか？
生成された <script type="application/ld+json">…</script> のコードを、対象ページのHTMLの <head> 内（または <body> 内でも可）に貼り付けます。通常はサイト全体の運営組織を表すため、トップページに1つ設置するのが一般的です。コピーボタンでコード全体をコピーし、テンプレートやCMSの共通ヘッダーに追加してください。
sameAsには何を入力すればいいですか？
sameAsには、その組織を表す公式な別ページのURLを入力します。具体的にはX（旧Twitter）・Facebook・Instagram・YouTube・LinkedInなどの公式SNSアカウントや、Wikipedia・公式プロフィールページのURLです。本ツールでは1行に1つのURLを入力すると、自動的にsameAsの配列として出力されます。組織の同一性を検索エンジンに伝える手がかりになります。
入力した情報は外部に送信されますか？
いいえ。本ツールの処理はすべてお使いのブラウザ内（クライアントサイド）のJavaScriptだけで完結します。入力した会社名・住所・電話番号・メールアドレスなどがサーバーへ送信・保存されることはありません。生成結果もその場で表示するだけなので、安心してご利用いただけます。
空欄の項目はどうなりますか？
名称以外の項目は任意です。入力を空欄のままにした項目は、生成されるJSON-LDから自動的に省略されます。たとえばメールアドレスを入力しなければemailプロパティは出力されません。住所も、市区町村や郵便番号など入力した項目だけがPostalAddressの中に含まれます。必要な情報だけを埋めれば、無駄のない構造化データを作成できます。
