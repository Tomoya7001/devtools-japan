音声文字起こし（リアルタイム）

マイクに話すだけで、ブラウザ上で音声をテキストに変換。アップロード不要・時間無制限

お使いのブラウザは音声認識に対応していません。
このツールはブラウザの音声認識機能（Web Speech API）を利用します。Firefox などの一部ブラウザでは動作しないため、Google Chrome または Microsoft Edge でのご利用をおすすめします。ページ下部の使い方・コツの解説は、どのブラウザでもご覧いただけます。
マイクの使用許可を求められたら「許可」を選択してください
認識結果（直接編集できます）0文字
プライバシーについて：音声データの録音・保存は行いません。認識はブラウザ内蔵の音声認識機能（Chromeの場合はGoogleの音声サービス）を利用します。ファイルのアップロードは不要で、認識結果のテキストが当サイトのサーバーに送信されることもありません。

無料・時間無制限のブラウザ文字起こしツールの使い方

本ツールは、マイクに向かって話すだけで音声をリアルタイムにテキストへ変換する無料の文字起こしツールです。音声ファイルのアップロードは不要、会員登録も不要で、利用時間の制限もありません。ブラウザだけで完結するので、ソフトのインストールなしにすぐ使えます。

使い方（3ステップ）

1. 認識する言語を選びます（日本語・英語・中国語・韓国語に対応）。
2. 「文字起こしを開始」ボタンを押し、ブラウザのマイク使用許可ダイアログで「許可」を選択します。
3. マイクに向かって話すと、認識中の文字がグレーで表示され、確定するとテキストエリアに追記されていきます。停止ボタンを押すまで連続して認識し続けます。

認識結果はテキストエリアで直接編集できます。誤認識した箇所はその場で修正し、「コピー」や「.txtダウンロード」でそのまま持ち出せます。最近の Chrome では日本語の句読点がある程度自動で挿入されますが、入らない場合は「。」挿入ボタンで手動補完できます。

対応ブラウザ

ブラウザ対応状況備考
Google Chrome（PC / Android）◎ 推奨最も安定。日本語の句読点自動挿入にも対応
Microsoft Edge○ 対応Chromeと同系エンジン。ほぼ同等に動作
Safari（Mac / iPhone）△ 一部対応比較的新しいバージョンで動作。挙動に差異あり
Firefox✕ 非対応音声認識API未対応のため利用不可

こんな場面で使えます

会議・打ち合わせの議事メモ、インタビューや取材のテキスト化、講義・セミナーの記録、ブログや原稿の音声入力（キーボードより速い場合も）、思いついたアイデアのメモ、語学の発音チェック（英語で話して正しく認識されるか確認）など。長時間の会議でも分数を気にせず回しっぱなしにできるのが特長です。

認識精度を上げるコツ

マイクとの距離・環境

マイクとの距離は15〜30cm程度が目安です。近すぎると息のノイズを拾い、遠すぎると音量不足で認識率が下がります。エアコンやテレビの音などの背景ノイズが少ない静かな環境ほど精度が上がります。会議で使う場合は、マイクを発言者の近くに置くか、外付けマイクの利用がおすすめです。

話し方

極端な早口を避け、一文ずつ区切ってはっきり話すと確定が速く、精度も安定します。専門用語・固有名詞・数字の羅列は誤認識されやすいため、認識後にテキストエリアで直接修正してください。無音が続くと認識が一時的に区切られますが、本ツールは自動で再開するため、停止ボタンを押すまで話し続けられます。

他の文字起こしサービスとの違い

Notta や Rimo Voice などの文字起こしサービスの多くは、無料プランに「月○分まで」といった分数制限があり、継続利用には月額料金がかかります。本ツールはブラウザ内蔵の音声認識機能を利用するため、完全無料・時間無制限・登録不要で使えます。また、音声の録音・保存を一切行わないため、録音データがサービス側に残る心配がありません。一方で、話者分離（誰が話したかの識別）や音声ファイルのアップロードには現状対応していないため、それらが必要な場合は専用サービスとの使い分けをおすすめします。

よくある質問

本当に無料ですか？時間制限はありますか？
はい、完全無料で時間制限もありません。会員登録も不要です。多くの文字起こしサービスにある「月○分まで」といった分数制限はなく、何時間でも何回でも利用できます。
音声ファイル（録音データ）の文字起こしはできますか？
現在はマイクからのリアルタイム入力のみに対応しています。音声ファイルのアップロードによる文字起こしは今後の対応を予定しています。録音済みデータを文字起こししたい場合は、スピーカーで再生した音声をマイクで拾わせる方法でも一定の精度で認識できます。
対応ブラウザは何ですか？
Google Chrome と Microsoft Edge（PC・Android）で利用できます。Safari も比較的新しいバージョンで動作します。Firefox は音声認識APIに未対応のため利用できません。最も安定して動作する Chrome の利用を推奨します。
認識精度はどのくらいですか？
静かな環境ではっきり話した場合、日本語で実用的な精度が得られます。マイクとの距離を15〜30cm程度に保ち、早口を避けて一文ずつ区切って話すと精度が上がります。専門用語や固有名詞は誤認識されることがあるため、認識後にテキストエリアで直接修正してください。
音声データはどこかに送られますか？保存されますか？
本ツールが音声を録音・保存することはありません。音声認識にはブラウザ内蔵の音声認識機能を利用しており、Chromeの場合は認識処理のためにGoogleの音声サービスへ音声が送られます。認識結果のテキストはお使いのブラウザ内にのみ表示され、当サイトのサーバーへ音声・テキストが送信されることは一切ありません。
