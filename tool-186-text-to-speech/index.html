読み上げプレビュー

再生すると、読み上げ中の文がここでハイライト表示されます。
この読み上げはブラウザ標準の音声合成API（Web Speech API / window.speechSynthesis）を使って端末内で処理します。利用できる音声はOS・ブラウザに依存し、日本語音声（ja-JP）を優先して初期選択します。音声のMP3ダウンロードはAPIの制約上できず、その場での読み上げ専用です。

テキスト読み上げツールの使い方

入力した文章を、ブラウザだけで音声に変換して読み上げる無料ツールです。原稿やメール、学習用の英文・和文、ナレーションの下読みなどを、目で追う代わりに耳で確認できます。インストールや会員登録は不要で、読み上げ処理はすべてお使いの端末内で完結します。テキストを入力し、必要に応じて音声・速度・ピッチ・音量を調整したうえで「再生」ボタンを押すだけで、すぐに読み上げが始まります。

読み上げ中は、今どの文を読んでいるかがプレビュー欄でハイライト表示されるため、原稿のどこを読んでいるかが一目でわかります。「一時停止」で途中で止めて再開したり、「停止」で最初からやり直したりも可能です。速度は0.5倍のゆっくりから2倍の早口まで、ピッチ（声の高さ）や音量とあわせて細かく調整できます。

こんな用途に

書いた文章を音で聞いて誤字脱字や言い回しをチェックする校正・推敲に、プレゼンやナレーション原稿の読み上げリハーサルに、語学学習での発音・イントネーションの確認に、長文を耳で聞いて「ながら読み」したいときに。日本語だけでなく、端末に入っている音声によっては英語など他言語の読み上げにも対応します。

仕組みと注意点

本ツールは、ブラウザに標準搭載されている音声合成API（Web Speech API）を利用しています。テキストをこのAPIに渡すと、端末側の音声エンジンが読み上げ音声を生成してスピーカーから再生します。JavaScript側で独自にテキストを外部サーバーへ送信することはありません。利用できる音声（ボイス）はOSやブラウザによって異なり、音声メニューには端末にインストールされている音声の一覧が表示されます。日本語音声（ja-JP）があれば初期状態で優先的に選択します。

音声が表示されない・読み上げされないとき

音声メニューが空になる場合、ブラウザが音声一覧をまだ読み込んでいない可能性があります。本ツールは音声一覧が更新されるタイミング（voiceschangedイベント）を監視して自動で反映しますが、ページを再読み込みすると改善することがあります。日本語音声が一つも見つからない場合は、OSの音声設定・アクセシビリティ設定から日本語の音声を追加してください。また、他のツールと異なり、これは音声合成（テキスト→音声）専用で、音声からテキストを起こす文字起こしや、読み上げ時間の目安を計算する機能とは役割が異なります。

よくある質問

音声ファイル（MP3）としてダウンロードできる？
いいえ。本ツールはブラウザ標準の音声合成API（Web Speech API）を利用しており、この仕組みはスピーカーから音声を再生することはできても、生成された音声データをMP3やWAVなどのファイルとして取り出す機能を提供していません。そのため技術的な制約上、読み上げ音声をファイル保存・ダウンロードすることはできず、あくまでその場での読み上げ（読み上げ再生）専用です。
日本語の読み上げに対応している？
はい。日本語（ja-JP）の音声がインストールされている端末では日本語テキストを自然に読み上げできます。利用できる音声はOSやブラウザによって異なり、音声選択メニューには端末に入っている音声の一覧が表示されます。日本語音声が見つからない場合は、OS側の音声設定から日本語の音声を追加してください。
速度やピッチ、音量は調整できる？
はい。速度（0.5〜2倍）、ピッチ（声の高さ）、音量をスライダーで自由に調整できます。速度を上げれば早口の確認に、下げればゆっくりとした聞き取りやすい読み上げになります。設定を変更したあとに再生し直すと、新しい設定が反映されます。
入力したテキストは外部に送信される？
本ツールのJavaScriptはテキストをサーバーへ送信しません。読み上げ処理はブラウザの音声合成APIに直接渡して端末内で完結します。ただし一部のブラウザやOSでは、音声合成そのものがOS・ブラウザの実装によりクラウド処理される場合があります。機密性の高い文章の取り扱いには各ブラウザの仕様もご確認ください。
読み上げ中の文がハイライトされるのはなぜ？
音声合成APIの読み上げ位置イベント（onboundary）を利用して、今読み上げている位置を推定し、その文をハイライト表示しています。文章のどこを読んでいるかが視覚的にわかるため、原稿の確認や語学学習に便利です。なお端末や音声によってはこの位置イベントに対応しておらず、ハイライトが動作しない場合があります。
