llms.txt ジェネレーターの使い方

        
llms.txt は、生成AI（大規模言語モデル）にWebサイトの概要と重要なページの一覧を伝えるための Markdown 形式のファイルです。本ツールを使えば、サイト名・概要・主要ページを入力するだけで、標準フォーマットに沿った llms.txt をリアルタイムに生成できます。インストールや会員登録は不要で、すべての処理はブラウザ内で完結します。

        
まず「サイト基本情報」にサイト名と概要、必要ならサイトURLを入力します。次に「セクションと主要ページ」で、Docs や Optional といった見出しごとにページを追加します。各行にはページのタイトル・URL・補足説明を入力でき、下部の生成結果が即座に更新されます。行は矢印ボタンで並べ替え、不要な行やセクションは削除できます。最後に「コピー」または「ダウンロード」で出力を取得し、ファイル名を llms.txt としてサイトのルートに設置してください。

        
LLMO・AEO対策としての位置づけ

        
検索の主役が従来型の検索エンジンから、AIによる回答生成へと広がる中で、AIにサイトの構造を正しく伝えることの重要性が高まっています。llms.txt は、人間向けのHTMLとは別に、機械が読みやすい索引を提供する試みです。LLMO（LLM最適化）やAEO（回答エンジン最適化）の観点から、robots.txt・sitemap.xml と並ぶ補助ファイルとして用意しておくと、サイトの全体像を短時間で把握してもらいやすくなります。


        
llms.txt の標準フォーマット

        
llms.txt は緩やかな標準に基づいた、シンプルな Markdown ファイルです。基本構造は次のとおりで、本ツールもこの書式で出力します。

        

        

            
要素書式説明

            
サイト名# サイト名ファイル先頭のH1見出し。必須項目

            
概要> 概要文引用ブロックでサイトの要約を1〜数行で記述

            
セクション## Docs / ## OptionalH2見出しでページを分類。任意の見出しを複数作成可

            
リンク行- [タイトル](URL): 補足Markdownリンクの箇条書き。補足説明は任意

        

        

        
「## Optional」は、AIが必要に応じて省略してよい補助的な情報をまとめる慣例的なセクション名です。重要なドキュメントは Docs に、補足的なページは Optional にといった形で整理すると、AIが優先順位を判断しやすくなります。見出し名は自由に変更できるため、Guides・API・Blog など、サイトに合わせた分類も可能です。


        
よくある質問

        
llms.txt とは何ですか？
llms.txt は、Webサイトのルート（例: https://example.com/llms.txt）に設置する Markdown 形式のテキストファイルです。生成AI（大規模言語モデル）に対して、サイトの概要と重要なページの一覧を機械が読み取りやすい形で伝えることを目的としています。H1見出しにサイト名、引用（>）で概要、H2見出しごとにリンクの箇条書きを並べる緩やかな標準フォーマットで、LLMがサイトの全体像を短時間で把握できるようにします。

        
llms.txt を置くとAIに読まれますか？
llms.txt はあくまで提案的な仕様であり、設置すれば必ずすべてのAIに読み込まれることを保証するものではありません。対応するクローラーやツールが増えつつある段階です。ただし人間にもAIにも読みやすい構造化された索引を用意しておくことは、LLMO（LLM最適化）やAEO（回答エンジン最適化）の一環として有効で、robots.txt や sitemap.xml と併用することが推奨されます。

        
どんなフォーマットで生成されますか？
本ツールは llms.txt の標準的な書式で出力します。1行目に「# サイト名」、続けて「> 概要」の引用行、その後は「## Docs」「## Optional」などのH2セクション見出しごとに「- [タイトル](URL): 補足説明」というMarkdownリンクの箇条書きを並べます。タイトルとURLが未入力の行は自動的に除外されるため、空欄を気にせず入力できます。

        
セクションは複数作れますか？
はい。「セクションを追加」ボタンで Docs、Optional、Guides など任意の見出しをいくつでも追加できます。各セクション内では行の追加・削除に加え、上下の矢印で並べ替えができます。Optional セクションはAIが省略してよい補助的な情報を示す慣例的な見出しで、重要度に応じてページを整理できます。

        
生成した llms.txt はどう使いますか？
生成結果を「コピー」または「ダウンロード」し、ファイル名 llms.txt としてWebサイトのルートディレクトリ（トップページと同じ階層）に設置します。URLが https://example.com/llms.txt で開ける状態にしてください。内容はすべてブラウザ内で処理され、サーバーには送信されないため、公開前のサイト情報でも安全に作成できます。
