使い方

1. 上のエリアに画像をドラッグ&ドロップするか、クリックして画像ファイルを選びます。

2. 画像に含まれるEXIF（撮影日時・カメラ機種・レンズ・GPS位置情報・向き・解像度など）を自動で一覧表示します。GPS座標がある場合は地図リンクを表示します。

3. 「EXIFを削除してダウンロード」を押すと、位置情報などのメタデータを取り除いた画像を保存できます。

画像はサーバーに送信されず、解析も削除もすべてあなたの端末（ブラウザ）の中だけで行われます。

EXIFの解析は外部ライブラリを使わず、画像のバイナリ（ArrayBuffer / DataView）から APP1・TIFF・IFD の主要タグを直接読み取っています。EXIFを持たない画像や記録されていない項目は「EXIFなし」または空欄となります。GPS座標の地図リンクは緯度経度を外部地図サービスで開くもので、画像そのものは送信されません。

画像EXIF確認・削除ツールの使い方

スマートフォンやデジタルカメラで撮影した写真には、EXIF（Exif）と呼ばれるメタデータが自動的に埋め込まれています。このツールは、画像をドラッグ&ドロップまたは選択するだけで、撮影日時・カメラの機種・レンズ・シャッタースピードやF値などの撮影設定・画像の向き・解像度、そして端末の設定によってはGPSによる撮影場所の緯度経度まで、一覧で確認できる無料ツールです。GPS座標が記録されている場合は、緯度経度とともに地図で開くためのリンクも表示します。

確認だけでなく、ワンクリックでEXIFを削除した画像を書き出せます。写真をSNSやフリマアプリ、ブログに投稿する前に、自宅や職場などの位置情報が写真から特定されてしまうのを防ぐために役立ちます。画像はサーバーにアップロードされず、EXIFの解析も削除もすべてお使いのブラウザ内（JavaScript）で完結するため、プライバシーを気にせず安心してご利用いただけます。

こんな用途に

フリマ・オークションの出品写真から自宅の位置情報を消したいとき、SNSやブログに写真を載せる前にプライバシー情報を除去したいとき、写真の撮影日時やカメラ設定を後から確認したいとき、他人から受け取った画像に位置情報が含まれていないか点検したいときなどに便利です。撮影に使われた機材や設定を調べたいカメラ愛好家の方にもお使いいただけます。

EXIFに含まれる主な情報

EXIFには撮影に関するさまざまな情報が含まれます。中でもGPSによる位置情報は、写真がどこで撮影されたかを緯度経度で特定できてしまうため、公開前の削除が特に重要です。主な項目は次のとおりです。

項目内容
撮影日時写真が撮影された年月日・時刻（DateTimeOriginal）
カメラ機種撮影に使われた端末やカメラのメーカー・機種名
レンズ・撮影設定レンズ名、F値、シャッタースピード、ISO感度、焦点距離
GPS位置情報撮影場所の緯度・経度（記録されている場合）
向き（Orientation）画像の回転・反転情報
解像度画像の幅・高さ（ピクセル）や解像度

EXIF削除の仕組み

本ツールのEXIF削除は、読み込んだ画像を一度canvas（キャンバス）に再描画し、その結果をJPEGまたはPNGとして書き出すことで実現しています。canvasに描き直された画像にはEXIFなどのメタデータが引き継がれないため、撮影日時やGPS位置情報を含まないクリーンな画像が得られます。見た目のピクセルはそのまま維持されるので、位置情報などの情報だけを取り除いて安全に共有できます。すべての処理はブラウザ内で行われ、画像が外部に送信されることはありません。

よくある質問

EXIFとは何ですか？
EXIF（Exchangeable Image File Format）は、デジタルカメラやスマートフォンで撮影した画像に自動で埋め込まれるメタデータです。撮影日時、カメラの機種、レンズ、シャッタースピードやF値などの撮影設定、画像の向き、そして端末の設定によってはGPSによる撮影場所の緯度経度まで含まれます。本ツールは画像を読み込むだけでこれらの情報を一覧表示します。
画像はサーバーにアップロードされますか？
いいえ。本ツールはすべての処理をお使いのブラウザ内（JavaScript）で完結します。画像がサーバーに送信されることは一切なく、EXIFの解析も削除もあなたの端末の中だけで行われます。会員登録やインストールも不要で、プライバシーに配慮した設計です。
EXIFを削除するとどうなりますか？
EXIF削除では、画像をcanvasに再描画してからJPEGまたはPNGとして書き出すため、撮影日時・カメラ機種・GPS位置情報などのメタデータが取り除かれます。SNSやフリマ、ブログに写真を載せる前に位置情報などのプライバシー情報を消したい場合に有効です。画像の見た目（ピクセル）はそのまま保持されます。
GPS位置情報が表示されないのはなぜですか？
すべての画像にGPS情報が含まれるわけではありません。位置情報の記録をオフにして撮影した場合、スクリーンショットやSNS経由でダウンロードした画像、EXIFを持たないPNGなどでは、GPS座標が記録されていないため表示されません。この場合は「EXIFなし」または該当項目が空欄となります。
対応している画像形式は？
EXIF情報の読み取りは、主にJPEG（.jpg / .jpeg）形式に対応しています。JPEGはカメラやスマートフォンの標準形式で、EXIFを持つ代表的な形式です。PNGなどEXIFを持たない形式を読み込んだ場合は「EXIFなし」と表示しますが、いずれの形式でもcanvas再描画によるメタデータ削除・ダウンロードは利用できます。
