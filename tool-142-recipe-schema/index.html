レシピ リッチリザルト要件のヒント

    生成される JSON-LD は schema.org の Recipe 型に基づきます。空欄のフィールドは自動的に除外され、調理時間は分入力から ISO 8601（PT#H#M）へ変換されます。実装後は Google のリッチリザルトテストで検証することを推奨します。すべての処理は端末内で完結し、入力内容は送信されません。

    Recipe構造化データ生成ツールの使い方

    レシピ名・画像・材料・手順・調理時間などを入力するだけで、schema.org の Recipe 型に準拠した JSON-LD 構造化データをリアルタイムに生成する無料ツールです。生成された ld+json のスクリプトタグ一式をコピーして、レシピページのHTMLに貼り付けるだけで、検索エンジンにレシピ内容を正しく伝えられます。インストールや会員登録は不要で、入力した内容はサーバーに送信されず、すべての生成処理がお使いのブラウザ内で完結します。

    使い方はシンプルです。まず必須のレシピ名と画像URLを入力し、続いて作者・説明・調理時間・分量・カテゴリなどを必要な範囲で埋めます。材料と手順は「行を追加」ボタンで項目を増やし、不要な行は削除できます。入力を変更するたびに下部の出力エリアの JSON-LD が即座に更新されるので、内容を確認しながら仕上げられます。空欄の項目は出力から自動で除外されるため、埋めたい項目だけを入力すれば有効な構造化データになります。

    調理時間のISO8601変換について

    schema.org の Recipe では、準備時間（prepTime）・調理時間（cookTime）・合計時間（totalTime）を ISO 8601 の期間表記で記述する必要があります。本ツールでは調理時間を「分」で入力すると、自動的に PT#M 形式へ変換します。60分以上の場合は時間と分に分解し、たとえば90分なら PT1H30M と出力します。入力欄の下に変換後の値がリアルタイムで表示されるので、変換結果をその場で確認できます。

    生成されるプロパティ

    本ツールが出力する主な Recipe プロパティは次のとおりです。必須級の項目と任意項目を区別して、必要なものだけを入力してください。

    プロパティ内容形式
    nameレシピ名文字列（必須）
    image料理の画像URL文字列または配列（推奨）
    author作者Person 型
    prepTime / cookTime / totalTime各調理時間ISO 8601（PT#H#M）
    recipeIngredient材料文字列の配列
    recipeInstructions手順HowToStep の配列
    nutrition栄養情報（カロリー）NutritionInformation 型
    aggregateRating評価の平均と件数AggregateRating 型

    リッチリザルトのための推奨事項

    レシピのリッチリザルト表示を狙う場合、少なくともレシピ名と高解像度の画像を用意し、材料・手順・調理時間をできるだけ揃えることが推奨されます。評価（aggregateRating）を含めると、検索結果に星評価が表示される可能性が高まります。ただし評価は実際のユーザーレビューに基づくものである必要があり、実体のない評価の記述はガイドライン違反となる点に注意してください。手順は各ステップを HowToStep として分けて記述すると、内容がより正確に伝わります。実装後は Google のリッチリザルトテストや schema.org バリデータでエラー・警告を確認しましょう。

    よくある質問

    Recipeの構造化データとは何ですか？
    Recipe構造化データは、レシピのタイトル・材料・手順・調理時間・評価などの情報を検索エンジンが理解できる形式（schema.org の Recipe 型）で記述したものです。本ツールは入力内容から JSON-LD 形式の構造化データを生成します。これをレシピページのHTMLに埋め込むと、Googleがレシピ内容を正しく認識しやすくなり、検索結果でのレシピリッチリザルト（画像・評価・調理時間つきの表示）の対象になり得ます。
    調理時間はどう入力すればよいですか？
    準備時間・調理時間・合計時間はそれぞれ「分」で入力してください。ツールが自動的に schema.org が要求する ISO 8601 の期間表記（例: 45分なら PT45M、90分なら PT1H30M）へ変換して JSON-LD に出力します。60分以上は時間と分に分解されます。値が空欄または0の時間フィールドは出力から自動的に除外されます。
    材料や手順は何行でも追加できますか？
    はい。材料（recipeIngredient）と手順（recipeInstructions）はどちらも「行を追加」ボタンで必要な数だけ増やせ、不要な行は削除できます。材料は1行1項目としてそのまま配列に、手順は各ステップが schema.org の HowToStep 型（@type: HowToStep）のオブジェクトとして順番どおりに出力されます。空欄の行は自動的に除外されます。
    入力していない項目はどうなりますか？
    空欄のフィールドは JSON-LD に含まれず自動的に除外されます。これにより、値のないプロパティが空文字やnullとして残ることを防ぎ、常に有効な構造化データを生成できます。作者・カテゴリ・料理ジャンル・栄養情報・評価などは任意項目のため、必要なものだけ入力すれば構いません。
    生成したJSON-LDはどこに貼り付けますか？
    生成された ld+json のスクリプトタグ一式をコピーし、レシピページのHTMLの head 内、または body 内に貼り付けてください。JSON-LD はページの表示位置に影響しないため配置場所は比較的自由です。貼り付け後は Google のリッチリザルトテストや schema.org バリデータで、エラーや警告がないか確認することを推奨します。
