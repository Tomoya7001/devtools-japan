title/meta description チェッカーの使い方

SEOで重要なtitleタグとmeta descriptionの「長さ」を、ブラウザだけでリアルタイムに確認できる無料ツールです。入力欄にタイトルと説明文を打ち込むと、実際の文字数、全角2・半角1で数えたカウント、そして表示ピクセル幅の目安を即座に表示します。推奨範囲に収まっているかは色付きバーで判定でき、緑なら適正、黄色は不足ぎみ、赤は超過を表します。

さらにGoogle検索結果を模したSERP風プレビューを備えており、PC表示とモバイル表示を切り替えて、実際にどこまで表示されどこで見切れる（省略される）かをシミュレーションできます。公開前のタイトル案や、リライト時の説明文調整に役立ちます。入力内容はすべて端末内で処理され、外部に送信されません。

推奨される長さの目安

日本語のtitleは全角で約28〜32文字、半角換算で約60文字、ピクセル幅にしておおよそ600pxまでが目安です。これを超えると検索結果でタイトル末尾が省略されやすくなります。meta descriptionは全角で約80〜120文字、おおよそ920pxまでが目安で、長すぎると末尾が切られ、短すぎると訴求力が下がります。

なぜ文字数だけでなくピクセル幅が大切か

Google検索結果のタイトルや説明文は「文字数」ではなく「表示ピクセル幅」で見切れるかどうかが決まります。同じ文字数でも、幅の広い漢字や全角記号が多いタイトルと、細い半角英数字が多いタイトルでは実際の表示幅が変わります。そのため本ツールでは文字数カウントに加えてピクセル幅の目安も推定し、両方の観点から適正な長さを判断できるようにしています。

絵文字・記号の扱い

絵文字や特殊記号も概算で幅を計算します。ただし環境によって表示幅は前後し、検索結果で絵文字が表示されない場合もあります。装飾記号を多用すると本文の情報量が削られるため、キーワードを優先しつつ、見え方は最終的に実際の検索結果で確認することをおすすめします。

よくある質問

titleタグは何文字が最適ですか？
日本語のtitleは全角で約28〜32文字、半角換算で約60文字（おおよそ600ピクセル幅）が目安です。Google検索結果ではピクセル幅で見切れが決まるため、文字数だけでなく本ツールが表示するピクセル幅の目安も合わせて確認するのがおすすめです。範囲内なら緑、超過は赤のバーで判定できます。
meta descriptionは何文字が最適ですか？
日本語のmeta descriptionは全角で約80〜120文字、おおよそ920ピクセル幅までが目安です。長すぎると検索結果で末尾が省略され、短すぎると情報量が不足します。本ツールでは推奨範囲を色バーで示し、SERP風プレビューでどこまで表示されるかを確認できます。
文字数はどう数えていますか？
本ツールは実際の文字数に加えて、全角を2・半角を1として数えた「カウント」も表示します。日本語のひらがな・漢字・全角記号は2、半角英数字や半角スペースは1として計算します。あわせてピクセル幅の目安も推定するため、和文と欧文が混在するタイトルでも見え方を把握しやすくなっています。
ピクセル幅の判定は正確ですか？
ピクセル幅はブラウザのcanvas機能で文字の描画幅を測る簡易推定です。Google検索側の実際のフォントや環境とは差が出るため、あくまで見切れの目安としてご利用ください。絵文字や記号も概算で幅を計算しますが、環境により表示幅は前後します。最終的な見え方は実際の検索結果でご確認ください。
入力したデータはサーバーに送信されますか？
いいえ。titleやmeta descriptionの文字数・ピクセル幅の計算、SERPプレビューの生成はすべてお使いのブラウザ内で完結し、入力内容が外部サーバーへ送信されることはありません。公開前の下書きやクライアントワークのタイトル案も安心してチェックできます。
