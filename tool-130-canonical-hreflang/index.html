canonical・hreflang タグ生成

正規URLと言語別の代替URLからタグ一式を自動生成

正規URL（canonical）

言語×地域ごとの代替URL（hreflang）

生成されたタグ

生成した link タグは、対象となる全ての言語・地域版ページの <head> 内に同じセットで設置してください。hreflang は双方向（相互参照）が必須です。ページAがBを指すなら、BもAを指し返す必要があります。全ページに同じタグ一式を貼れば自動的に相互参照が成立します。各ページの canonical は、そのページ自身のURLに合わせて個別に調整してください。

canonical・hreflang タグ生成ツールの使い方

多言語・多地域サイトで必要になる「正規URL（canonical）」と「代替URL（hreflang）」の link タグを、フォームに入力するだけで自動生成する無料ツールです。正規URLと、言語×地域ごとの代替URLを追加していくと、<link rel="canonical"> と <link rel="alternate" hreflang="..."> のタグ一式（x-default 含む）をリアルタイムに生成し、そのままコピーして各ページの <head> に貼り付けられます。インストールや会員登録は不要で、すべての処理はお使いのブラウザ内で完結します。

使い方はかんたんです。まず上部の「正規URL」欄に、このページの代表URLを絶対URL（https:// から始まる形式）で入力します。次に「言語を追加」でhreflang値（ja、en-US、zh-Hans など）と、その言語版のURLを入力していきます。x-default を含めるかどうか、canonicalを出力に含めるかどうかも切り替えられます。入力がゼロでもサンプルのタグが表示されるので、まずは形を確認してから自分のURLに書き換えるのもおすすめです。

hreflang値の書き方

hreflang属性の値は、「言語コード」単体、または「言語コード-地域コード」の組み合わせで指定します。言語コードはISO 639-1の2文字小文字、地域コードはISO 3166-1 alpha-2の2文字大文字を使い、ハイフンでつなぎます。地域コードは省略でき、言語だけの指定も有効です。本ツールは入力した値がこの形式に沿っているかを簡易チェックし、妥当なら緑、形式に問題がありそうなら赤のヒントを表示します。

hreflang値意味種別
ja日本語（地域指定なし）言語のみ
en英語（地域指定なし）言語のみ
en-US英語（アメリカ）言語＋地域
en-GB英語（イギリス）言語＋地域
zh-Hans簡体字中国語言語＋表記
zh-Hant繁体字中国語言語＋表記
x-default一致しないユーザー向けの既定特別値

hreflangは双方向（相互参照）が必須

hreflangの指定で最も間違えやすいのが「相互参照（return tag）」です。ページAが「英語版はB」とhreflangで指すなら、ページBも「日本語版はA」と必ず指し返さなければなりません。片方向だけの指定は無効とみなされ、Google Search Console で「hreflangタグに返しタグがありません」というエラーになります。本ツールが生成するタグ一式は、全ての言語版ページに同じ内容で設置することを前提にしているため、各ページの <head> に貼れば自動的に相互参照が成立します。あわせて、各代替URLも自分自身を指すエントリを含めておくのが正しい形です。

x-default の役割

x-default は、用意したどの言語・地域にも一致しないユーザーに表示する既定URLを指定する特別なhreflang値です。言語選択ページや、最も汎用的な言語版のURLを指定するのが一般的です。必須ではありませんが、対象外の言語のユーザーの案内先を明示できるため設定が推奨されます。本ツールでは x-default を含めるかどうかを選べ、専用URLを入力しない場合は先頭の代替URLを既定として使用します。

よくある質問

canonicalとhreflangは何が違う？
canonical（正規URL）は、内容が重複・類似する複数のURLの中で「これが代表URLです」と検索エンジンに伝えるタグです。一方 hreflang は、同じ内容の言語別・地域別バージョンが複数あるときに「この言語・地域のユーザーにはこのURLを表示してほしい」と伝えるタグです。多言語サイトでは両方を併用し、各言語ページは自分自身を指すcanonicalを持ちつつ、全言語版をhreflangで相互にリンクします。
hreflangの値はどう書く？
hreflangの値は「言語コード」または「言語コード-地域コード」で指定します。言語はISO 639-1の2文字小文字（ja, en, zh など）、地域はISO 3166-1 alpha-2の2文字大文字（US, GB, JP など）で、ハイフンでつなぎます。例：ja（日本語）、en-US（アメリカ英語）、en-GB（イギリス英語）、zh-Hans（簡体字中国語）。地域コードは省略可能で、言語だけの指定も有効です。
x-defaultとは何？
x-defaultは、用意したどの言語・地域にも一致しないユーザー向けの既定URLを指定する特別なhreflang値です。言語選択ページや、最も汎用的な言語版のURLを指定するのが一般的です。必須ではありませんが、対象外の言語のユーザーがどのページに案内されるかを明示できるため、多言語サイトでは設定が推奨されます。本ツールでは x-default を含めるかどうかを選べます。
hreflangは相互（双方向）に必要？
はい。hreflangは双方向の参照が必須です。ページAがページBをhreflangで指すなら、ページBもページAを指し返す必要があります。片方向だけの指定は無効とみなされ、Google Search Consoleで「return tag（返しタグ）がない」というエラーになります。本ツールで生成したタグは、全ての言語版ページに同じセットを設置することを前提にしているため、各ページに貼れば自動的に相互参照が成立します。
生成したタグはどこに貼る？
生成された link タグは、各ページのHTMLの head 要素内に設置します。canonicalとhreflangのタグ一式を、対象となる全ての言語・地域版ページの head に同じ内容で貼り付けてください。なお各ページの自分自身を指すcanonicalは、そのページのURLに合わせて個別に調整する必要があります。HTMLのheadに設置できない場合は、HTTPレスポンスヘッダーやサイトマップでhreflangを指定する方法もあります。
