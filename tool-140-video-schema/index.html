    VideoObject 構造化データ生成ツールの使い方
    
        
    動画のタイトルや説明、サムネイル、公開日、再生時間などを入力するだけで、schema.org の VideoObject に準拠した JSON-LD をリアルタイムに生成する無料ツールです。生成されたコードをコピーして動画ページに貼り付ければ、Google の検索結果や動画タブでサムネイル付きのリッチリザルトとして表示される可能性が高まります。インストールや会員登録は不要で、入力内容はすべて端末内で処理されます。
    
        
    使い方はかんたんです。上のフォームに動画の情報を入力すると、下の「生成された JSON-LD」に結果が即座に反映されます。再生時間は「分」と「秒」の数値を入れるだけで、schema.org が求める ISO 8601 の期間形式へ自動変換されます。入力しなかった項目は出力から自動で除外されるため、必要な情報だけを含んだクリーンなコードが得られます。完成したら「コードをコピー」ボタンでクリップボードにコピーできます。

    再生時間の ISO 8601 変換について
    
        
    schema.org の VideoObject では、再生時間（duration）を ISO 8601 の期間形式で指定します。これは「PT」で始まり、続けて時間・分・秒をそれぞれ H・M・S の記号で表す書き方です。たとえば8分30秒なら PT8M30S、1分ちょうどなら PT1M、45秒なら PT45S となります。本ツールでは分と秒の数値を入力するだけで、この形式へ自動変換するため、記号の組み立てを覚える必要はありません。分と秒がどちらも0の場合は、duration 項目自体を出力から除外します。
    
        
    サムネイルとリッチリザルト要件
    
        
    動画のリッチリザルトを狙う場合、Google は name・description・thumbnailUrl・uploadDate を必須項目としています。特にサムネイルは、16:9・4:3・1:1 など複数のアスペクト比の画像を提供することが推奨されているため、本ツールのサムネイルURL欄では改行区切りで複数のURLを登録でき、出力では配列として生成されます。また、動画本体を示す contentUrl か、プレーヤーの embedUrl のいずれかを併せて指定しておくと、Google が動画を正しく認識しやすくなります。
    

        
    よくある質問
    
        
    VideoObject 構造化データとは何ですか？
    VideoObject は schema.org が定義する動画向けの構造化データ（スキーマ）で、動画のタイトル・説明・サムネイル・公開日・再生時間などを検索エンジンに機械可読な形で伝えるための仕様です。ページに JSON-LD として埋め込むと、Google の検索結果や動画タブでサムネイル付きのリッチリザルトとして表示される可能性が高まり、動画コンテンツの発見性向上につながります。
    
        
    再生時間はどう入力すればよいですか？
    本ツールでは再生時間を「分」と「秒」の数値で入力すると、schema.org が求める ISO 8601 の期間形式（例：8分30秒なら PT8M30S）へ自動変換して出力します。分だけ・秒だけの入力にも対応し、どちらも0の場合は duration 項目そのものを出力から除外します。手動で PT 表記を組み立てる必要はありません。
    
        
    入力を空欄にしたフィールドはどうなりますか？
    空欄のフィールドは JSON-LD の出力から自動的に除外されます。不要な項目に空文字やダミー値が残らないため、そのままコピーしてページに貼り付けられます。何も入力していない状態でも、構造を確認できるようサンプルの VideoObject を表示するので、必要な項目を上書きしながら完成させられます。
    
        
    サムネイルは複数指定できますか？
    はい。サムネイルURL欄は改行区切りで複数のURLを入力でき、出力では thumbnailUrl が配列として生成されます。Google は 16:9・4:3・1:1 など複数のアスペクト比のサムネイル提供を推奨しているため、解像度やアスペクト比の異なる画像URLを複数登録しておくと、リッチリザルトでの表示に有利になります。
    
        
    生成した JSON-LD はどこに貼り付ければよいですか？
    出力された script type=application/ld+json のコードブロックをそのままコピーし、対象ページの head 内、または body 内に貼り付けてください。VideoObject は動画を実際に埋め込んでいるページに設置するのが基本です。貼り付け後は Google のリッチリザルトテストや Search Console のURL検査で、正しく認識されるかを確認することをおすすめします。
