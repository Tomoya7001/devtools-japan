Movie 構造化データのヒント

    生成される JSON-LD は schema.org の Movie 型に基づきます。空欄のフィールドは自動的に除外され、director・actor は Person 型、productionCompany は Organization 型、genre・actor は配列、上映時間は ISO 8601（PT2H16M）として出力されます。実装後は Google のリッチリザルトテストや schema.org バリデータで検証することを推奨します。すべての処理は端末内で完結し、入力内容は送信されません。

    Movie構造化データ生成ツールの使い方

    映画のタイトル・監督・出演者・公開日・上映時間・ジャンル・評価・画像などを入力するだけで、schema.org の Movie 型に準拠した JSON-LD 構造化データをリアルタイムに生成する無料ツールです。生成された ld+json のスクリプトタグ一式をコピーして、映画の作品ページやレビューページのHTMLに貼り付けるだけで、検索エンジンに作品の内容を正しく伝えられます。インストールや会員登録は不要で、入力した内容はサーバーに送信されず、すべての生成処理がお使いのブラウザ内で完結します。

    使い方はシンプルです。まず必須のタイトルを入力し、続いてあらすじ・公開日・上映時間・年齢制限・監督・制作会社・出演者・ジャンル・URL・画像・総合評価などを必要な範囲で埋めます。出演者（actor）とジャンル（genre）は1行1項目で入力すると配列として出力されます。上映時間は分数で入力すると自動的に ISO 8601 形式（PT2H16M）へ変換されます。入力を変更するたびに下部の出力エリアの JSON-LD が即座に更新されるので、内容を確認しながら仕上げられます。空欄の項目は出力から自動で除外されるため、埋めたい項目だけを入力すれば有効な構造化データになります。

    映画ページのSEOとリッチリザルト

    Googleは映画に関する検索で、作品名・監督・出演者・評価などをリッチな形式で表示することがあります。作品の情報を Movie 構造化データで明示することは、検索エンジンにコンテンツの内容を正確に伝える補助になります。director（監督）、actor（出演者）、datePublished（公開日）、duration（上映時間）、genre（ジャンル）、aggregateRating（総合評価）などを揃えると、作品像がより具体的に伝わります。なお評価はページに実際に表示されているものと一致させる必要があり、実在しない評価を記述するとGoogleのガイドライン違反になります。

    生成されるプロパティ

    本ツールが出力する主な Movie プロパティは次のとおりです。必須項目と任意項目を区別して、必要なものだけを入力してください。

    duration と aggregateRating の書き方

    上映時間（duration）は schema.org では ISO 8601 の期間形式が求められます。本ツールでは分数（例: 136）を入力すると自動的に PT2H16M のような形式へ変換します。すでに ISO 8601 形式で入力した場合はそのまま使用されます。総合評価（aggregateRating）は、平均評価値（ratingValue）とレビュー件数（reviewCount）の両方を入力すると schema.org の AggregateRating 型として出力されます。満点（bestRating）も指定できます。評価はページに実際に掲載されている集計値と一致させ、ユーザーに見えない評価を記述しないことが重要です。実装後は Google のリッチリザルトテストや schema.org バリデータでエラー・警告を確認しましょう。

    よくある質問

    Movieの構造化データとは何ですか？
    Movie構造化データは、映画のタイトル・監督・出演者・公開日・上映時間・ジャンル・評価などの情報を検索エンジンが理解できる形式（schema.org の Movie 型）で記述したものです。本ツールは入力内容から JSON-LD 形式の構造化データを生成します。映画のレビューページや作品紹介ページに埋め込むと、Googleが作品の内容を正しく認識しやすくなり、検索結果でのリッチな表示につながる手がかりになります。
    上映時間（duration）はどのように入力しますか？
    上映時間は分数（例: 136）で入力すると、ISO 8601 の期間形式（例: PT2H16M）に自動変換して出力します。すでに PT2H16M のような ISO 8601 形式で入力した場合はそのまま使用されます。schema.org の duration は ISO 8601 形式が求められるため、本ツールが自動で整形します。上映時間が不明な場合は空欄のままにすれば、duration プロパティは出力から除外されます。
    監督や出演者はどう入力しますか？
    監督（director）は氏名を1つ入力すると schema.org の Person 型のオブジェクトとして出力されます。出演者（actor）は1行1名で複数入力でき、それぞれ Person 型のオブジェクトの配列として出力されます。ジャンル（genre）も1行1項目で入力すると文字列の配列になります。空行は自動的に除外されるため、必要な人数・項目だけを入力すれば有効な構造化データになります。
    aggregateRating（総合評価）はどう出力されますか？
    平均評価値（ratingValue）とレビュー件数（reviewCount）を入力すると、schema.org の AggregateRating 型のオブジェクトとして出力されます。評価の最小値・最大値（bestRating・worstRating）も指定できます。評価値とレビュー件数の両方が入力されている場合に出力され、片方でも欠けている場合は aggregateRating プロパティ自体が除外されます。実在しない評価やユーザーに表示されていない評価を記述するとガイドライン違反になるため注意してください。
    生成したJSON-LDはどこに貼り付けますか？
    生成された ld+json のスクリプトタグ一式をコピーし、映画の作品ページやレビューページのHTMLの head 内、または body 内に貼り付けてください。JSON-LD はページの表示位置に影響しないため配置場所は比較的自由です。ページに実際に表示されている情報と構造化データの内容が一致していることが重要です。貼り付け後は Google のリッチリザルトテストや schema.org バリデータで検証することを推奨します。
