WebPとは？なぜWebP画像が増えているのか

WebP（ウェッピー）はGoogleが開発した画像形式で、同じ画質のJPGやPNGと比べて25〜35%ほど容量を小さくできるのが特徴です。ページの表示速度が改善しSEOにも有利なため、近年は多くのWebサイトが画像をWebPで配信するようになりました。ブラウザで画像を右クリック保存すると拡張子が「.webp」になっていて驚いた、という経験がある方も多いはずです。

WebPは可逆・非可逆の両方の圧縮に対応し、PNGのような透過（アルファチャンネル）も扱えます。モダンブラウザでの表示にはまったく問題ありませんが、いまだにWebPを読み込めない環境も残っています。

WebPが開けない・使えない時の対処法

古い画像編集ソフト、社内の申請システム、一部のブログ・ECサイトの入稿フォーム、古いバージョンのオフィスソフトなどはWebPに対応していないことがあります。こうした場面では、WebPを従来のJPGまたはPNGに変換してしまうのが最も確実な対処法です。

本ツールを使えば、保存したWebP画像をドラッグ＆ドロップするだけで一括でJPGやPNGに変換できます。写真ならJPG、透過やくっきりした図・ロゴならPNGを選ぶのが目安です。逆に、手元のJPG・PNGをWebPへ変換してWebサイトを軽量化する使い方もできます。

変換方向透過の扱い画質対応ブラウザ
WebP → JPG白背景で塗りつぶし非可逆（品質スライダーで調整）ほぼすべてのブラウザ
WebP → PNGそのまま保持可逆（劣化なし）ほぼすべてのブラウザ
JPG・PNG → WebPそのまま保持非可逆（品質スライダーで調整）Chrome・Edge・Firefox（Safari非対応）

なお、WebP→JPG・PNGの読み込みはSafari 16以降を含む主要ブラウザで動作しますが、非常に古いSafari（macOS Big Sur以前など）はWebPの読み込み自体に対応していない場合があります。その場合はChromeやEdgeでお試しください。

一括変換の使い方と大量変換の実用ガイド

  1. 変換方向（WebP→JPG / WebP→PNG / JPG・PNG→WebP）を選ぶ
  2. ファイルをまとめてドラッグ＆ドロップ（またはクリックして複数選択）
  3. 「一括変換する」を押すと1枚ずつ順番に変換され、一覧に変換前後のサイズが表示される
  4. 1枚ずつ個別にダウンロードするか、「まとめてZIPでダウンロード」で一括保存

JPGまたはWebPへ出力する場合は品質スライダー（0.1〜1.0）で圧縮の強さを調整できます。0.85前後なら見た目をほぼ保ったまま軽量化でき、0.6〜0.7まで下げるとさらに小さくなります。WebP→PNGは可逆圧縮のため品質指定はありません。

何枚まで一括変換できる？

本ツールに枚数制限はありません。多くのオンライン変換サービスは「1回20枚まで」「1日◯回まで」といった制限を設けていますが、本ツールはサーバーを経由せずブラウザ内で処理するため、そうした人為的な制限が不要です。理論上は1万枚でも変換できますが、実際の上限はお使いの端末のメモリに依存します。変換後のデータはダウンロードまでメモリ上に保持されるため、数千枚を超えるような大量変換では、数百枚ずつに分けて「変換→ZIPダウンロード→リセット」を繰り返すと安定して処理できます。

大量変換を安定させるコツ

  • 1枚あたりのファイルサイズが大きい（数十MB級の）画像は、まとめる枚数を減らす
  • 変換中は他の重いタブやアプリを閉じておく
  • ZIPダウンロード後に「リセット」を押してメモリを解放してから次のバッチを読み込む

読み込めないファイルが混ざっていても処理は止まりません。破損ファイルなどはエラーとして表示され、残りのファイルの変換はそのまま続行されます。

よくある質問

変換すると画質は劣化しますか？
出力先がJPGまたはWebPの場合は非可逆圧縮のため、品質スライダーの値に応じてわずかに画質が低下します（0.85前後なら見た目はほとんど変わりません）。WebP→PNGは可逆圧縮での保存となるため、変換時に画質は劣化しません。
一度に何枚まで変換できますか？
枚数の上限は設けていません。処理はお使いのブラウザのメモリ内で1枚ずつ順番に行われるため、実際に扱える枚数は端末の性能とファイルサイズに依存します。数百枚程度なら一般的なPCで問題なく動作します。数千枚を超える大量変換は、数百枚ずつに分けて実行すると安定します。
透過PNGをWebPやJPGに変換するとどうなりますか？
WebPは透過（アルファチャンネル）に対応しているため、PNG→WebPでは透過がそのまま保持されます。一方JPGは透過に対応していないため、WebP→JPGでは透明部分が白で塗りつぶされます。透過を保持したい場合はWebP→PNGを選んでください。
画像はサーバーにアップロードされますか？安全ですか？
いいえ。ファイルの読み込みから変換、ZIP作成、ダウンロードまですべてお使いのブラウザ内で完結し、サーバーへの送信は一切ありません。機密性の高い画像でも安全に変換でき、無料・登録不要で利用できます。
JPGやPNGからWebPへの逆変換もできますか？
はい。変換方向で「JPG・PNG→WebP」を選ぶと逆変換できます。ただしSafariはWebPの書き出し（エンコード）に対応していないため、この方向はChrome・Edge・Firefoxをご利用ください。WebP→JPG・PNGの方向はSafariを含む主要ブラウザで動作します。
