HTTPステータスコード早見表・検索

主要なコードの意味・使いどころ・SEO観点の注意を即時検索

検索・絞り込み

各項目をクリックすると「コード番号 英名」（例: 404 Not Found）をクリップボードにコピーします。分類タブと検索は組み合わせて絞り込めます。検索欄が空でも全件を表示します。掲載内容はRFC 9110 等の一般的な定義に基づく概説です。

HTTPステータスコードとは

HTTPステータスコードは、Webサーバがブラウザやクローラからのリクエストに対して「処理がどうなったか」を3桁の数字で返す仕組みです。先頭の数字で大きく5つに分類され、1xxは情報（処理継続中）、2xxは成功、3xxはリダイレクト（別URLへ誘導）、4xxはクライアント側の問題、5xxはサーバ側の問題を表します。開発時のデバッグはもちろん、SEOやクローラ制御の観点でも、どのコードを返すかは非常に重要です。

このツールでは、実務でよく使う主要なステータスコードを一覧化し、番号・英名・日本語のキーワードから即座に検索できます。各コードには英名・日本語の意味に加えて、実際の使いどころと、301と302の違いや404と410の使い分け、429・503のRetry-AfterといったSEO・クローラ観点の注意点を簡潔にまとめています。項目をクリックすればコードをコピーでき、ドキュメントやコミットメッセージへの記載にも便利です。

分類ごとの意味

分類意味代表的なコード
1xx 情報リクエストは受理され処理を継続中100, 101
2xx 成功リクエストは正常に処理された200, 201, 204
3xx リダイレクト要求の完了に追加の転送が必要301, 302, 304, 307, 308
4xx クライアントエラーリクエスト側に問題がある400, 401, 403, 404, 429
5xx サーバエラーサーバ側で処理に失敗した500, 502, 503, 504

SEO・クローラ観点で押さえたい点

サイト運営では、正しいステータスコードを返すことが検索評価の維持に直結します。恒久的なURL移転は301（またはメソッドを保つ308）で評価を引き継ぎ、一時的な転送は302・307を使います。削除して二度と戻さないページは410を返すとインデックスからの削除が速まり、まだ判断がつかないものは404にします。メンテナンス中は200で「準備中」を返さず、必ず503とRetry-Afterで一時的であることを伝えます。存在しないページを200で返す「ソフト404」はクロール効率を下げるため避けましょう。

よくある質問

301と302の違いは？
301 Moved Permanently は恒久的な移動で、検索エンジンは新URLへ評価を引き継ぎます。302 Found は一時的な移動で、元URLがそのうち戻る前提です。サイト移転やURL統合など恒久的な変更で誤って302を返すと評価が移らず順位に影響することがあります。恒久移転は301、期間限定は302または307を使い分けます。
404と410はどう使い分ける？
404 Not Found は「今見つからない」状態で一時的か恒久的かを示しません。410 Gone は意図的な削除で今後も復活しないことを明示し、検索エンジンは404より速くインデックスから削除する傾向があります。二度と戻さないと確定したURLは410、復活の可能性があるものは404が無難です。
429や503のRetry-Afterとは？
429 Too Many Requests や 503 Service Unavailable を返すとき、Retry-After ヘッダで再試行までの秒数や日時を伝えられます。Googlebotは503とRetry-Afterを一時的な状態として扱い、すぐにはインデックスから削除せず後で再クロールします。メンテナンス時は200ではなく503＋Retry-Afterを返すのが定石です。
200を返しているのに検索に出ないのはなぜ？
200はHTTP的に正常というだけで、インデックス可否は別問題です。noindex指定、canonicalが別URLを指す、コンテンツが薄い・重複、JavaScript描画依存で本文がHTMLに無い、などで200でも出ないことがあります。ソフト404になっていないかを確認し、noindexやcanonical、レンダリング結果を点検します。
307・308は301・302と何が違う？
308 Permanent Redirect は301と同じ恒久移転で、リクエストメソッドとボディを変えずに転送します。307 Temporary Redirect は302の厳密版で、こちらもメソッドを維持したまま一時転送します。APIやフォーム送信でPOSTを保ちたい場合は307/308が安全です。評価の引き継ぎは301と308が恒久、302と307が一時として扱われます。
