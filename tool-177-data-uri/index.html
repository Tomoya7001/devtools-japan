このツールは 100% クライアントサイドで動作します。読み込んだ画像・入力した data URI はサーバーに送信されず、すべてお使いのブラウザ内（FileReader / Blob）で処理されます。オフラインでも利用できます。

data URI 変換ツールの使い方

画像やSVG、Webフォントを Base64 の data URI（data:image/png;base64,... で始まる文字列）に変換したり、逆に data URI を画像へデコードして保存したりできる無料ツールです。ドラッグ＆ドロップまたはファイル選択で読み込むだけで、data URI とあわせて CSS の background-image 用スニペットや img タグ用スニペットを自動生成します。すべての処理はブラウザ内で完結し、ファイルがサーバーへ送られることはありません。

画像 → data URI（エンコード）

「画像 → data URI」タブでファイルを読み込むと、data URI 全体、CSS 用・HTML 用のスニペット、そしてプレビューが表示されます。元のファイルサイズ・data URI の文字数・増加率も確認できるため、埋め込みに適した小さな素材かどうかを判断できます。PNG・JPEG・GIF・WebP・SVG のほか、woff / woff2 / ttf / otf などのフォントファイルにも対応しています。

data URI → 画像（デコード）

「data URI → 画像」タブに data:... の文字列を貼り付けると、MIME タイプ・エンコード方式・デコード後のサイズを解析してプレビューを表示し、ボタン一つで元の画像ファイルとしてダウンロードできます。Base64 版はもちろん、URL エンコード（パーセントエンコード）された SVG の data URI にも対応しています。

data URI とは

data URI（データURIスキーム）は、ファイルの中身を URL の文字列そのものに埋め込むための仕組みです。data:[MIMEタイプ][;base64],[データ本体] という構造で、たとえば data:image/png;base64,iVBOR... のように表します。外部ファイルへのリンクではなく画像データ自体を HTML や CSS に直接書けるため、小さなアイコンやロゴを別ファイルにせずまとめられ、HTTP リクエスト数を減らせるという利点があります。

Base64 とサイズ肥大に注意

Base64 エンコードは 3 バイトを 4 文字で表現するため、data URI にすると元のファイルより約 33% サイズが増えます。数百バイト〜数 KB の小さなアイコンでは、リクエスト削減の効果がサイズ増を上回ることが多いですが、大きな写真を data URI 化すると HTML や CSS が肥大化し、キャッシュも効きにくくなって表示が遅くなります。目安として、繰り返し使う小さな素材は data URI、サイズの大きい画像は通常の画像ファイル参照、と使い分けるのがおすすめです。SVG はテキストなので Base64 より URL エンコード版の方が軽量です。

よくある質問

data URI（データURI）とは何ですか？
data URIは、画像などのファイルの中身をURLの文字列そのものに埋め込む仕組みです。data:image/png;base64,iVBORw0K... のように「data:」で始まり、MIMEタイプ・エンコード方式・Base64データが続きます。外部ファイルを参照せずHTMLやCSSの中に画像を直接書き込めるため、小さなアイコンなどをファイルとして分けずに扱いたいときに便利です。
このツールはアップロードされますか？安全ですか？
いいえ。変換はすべてお使いのブラウザ内（JavaScriptのFileReader）で完結し、画像やdata URIがサーバーへ送信・保存されることは一切ありません。機密画像や社外秘の素材でも、ネットワークに出さずに安全にBase64へ変換できます。オフライン環境でも動作します。
Base64にするとファイルサイズはどうなりますか？
Base64エンコードは3バイトを4文字で表現するため、元のファイルよりおよそ33%大きくなります。加えてdata:...;base64, のヘッダー分も増えます。数百バイト〜数KB程度の小さなアイコンやSVGでは、HTTPリクエストを減らせる利点がサイズ増を上回ることが多い一方、大きな写真をdata URIにするとHTMLやCSSが肥大化し読み込みが遅くなるため注意が必要です。
data URIをCSSやHTMLでどう使いますか？
CSSでは background-image: url(data:image/png;base64,...) のように url() の中にそのまま指定できます。HTMLでは img タグの src 属性に data URI を入れれば画像として表示されます。本ツールは変換後にCSSのbackground-image用とimgタグ用のスニペットを自動生成するので、コピーしてそのまま貼り付けられます。
SVGはBase64にしない方が良いのですか？
SVGはテキストなので、Base64ではなくURLエンコード（パーセントエンコード）でdata URIにする方がサイズが小さく、CSS内で扱いやすくなります。本ツールはSVGを読み込んだ際に、Base64版に加えてURLエンコード版のdata URIも生成します。多くの場合こちらの方が軽量なので、CSSの背景画像にはURLエンコード版の利用をおすすめします。
